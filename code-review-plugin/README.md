# Cloud Test Review — домашнее задание

Плагин IntelliJ IDEA проверяет **выделенный фрагмент** через облачную модель Mistral.
В этом репозитории плагин расположен отдельно от Selenium-тестов и не меняет их запуск.

## Установка

Готовый файл: `build/cloud-test-review-1.0.0.zip`.

1. IntelliJ IDEA → Settings → Plugins → шестерёнка → Install Plugin from Disk.
2. Выберите ZIP, примените изменения и перезапустите IDE, если она попросит.
3. Откройте `LoginPageTest.java` или `ConcurrentJUnitTestRunner.java`, выделите код.
4. Правой кнопкой → **Проверить качество тестов (AI)**.
5. Введите API-ключ Mistral и название доступной вам модели. По умолчанию — `mistral-small-latest`.
6. Нажмите **Проверить**. Заключение появится в отдельном окне; его можно выделить и скопировать.

API-ключ создаётся в Mistral Studio: https://console.mistral.ai/ . Нужны доступ к модели и доступная квота.
Ключ не сохраняется плагином. Можно задать переменную окружения `MISTRAL_API_KEY` **до запуска IDE**;
если IDE запущена из Dock, она может не получить переменную из терминала.
Выделенный код отправляется в Mistral только после нажатия «Проверить».

## Шесть правил

1. Надежность и стабильность тестов.
2. Ассерты и проверяемость результата.
3. Читаемость и намерение кода.
4. Хардкод и тестовые данные.
5. Повторяемость и DRY.
6. Архитектура тестов.

Ответ начинается с ясного заключения, затем содержит оценку по каждому правилу,
конкретные проблемы и приоритетные рекомендации. Номера строк относятся к выделенному фрагменту.
Модель должна отмечать недостаток контекста и не утверждать, что запускала тесты.

## Сборка и проверки

Для сборки используются JDK и библиотеки **установленной IntelliJ IDEA**, загрузок зависимостей нет.
Плагин использует Java 21. Проверенная сборка: текущая локальная IntelliJ IDEA 2026.2.
В дескрипторе указан минимум 2025.2; совместимость с другими версиями отдельно не проверялась.

```sh
python3 code-review-plugin/build.py
python3 code-review-plugin/check.py
```

Для другого расположения IDE:

```sh
python3 code-review-plugin/build.py --idea-home '/path/to/idea/Contents'
```

`check.py` настроен на стандартный путь macOS. Проверяет нумерацию строк, корректный,
пустой, повреждённый и обрезанный ответ модели, дескриптор и структуру ZIP.
Живой вызов API требует пользовательского ключа и проверяется после установки.
ZIP и классы находятся в игнорируемой папке `build/`; исходники можно добавить в Git.

## Архитектура

- `ReviewSelectedCodeAction` — выделение текста, фоновый запуск, отмена и ошибки.
- `CodeReviewRequestDialog` — API-ключ, модель и информация об отправке кода.
- `MistralCodeReviewClient` — правила, нумерация строк, HTTP-запрос, проверка ответа.
- `CodeReviewResultDialog` — заключение в прокручиваемом окне.
- `META-INF/plugin.xml` — регистрация действия в меню редактора.

Ограничение выделения — 30 000 символов. Тайм-аут подключения — 15 секунд,
запроса — 90 секунд. Отмена прерывает локальный HTTP-запрос, но облачный сервис
мог уже начать обработку. Ошибки API не выводят ключ или тело запроса.

## Демонстрация для сдачи

1. Проверить тест с осмысленным ассертом и ожиданием.
2. Проверить фрагмент без ассертов, с `Thread.sleep()` и паролем в коде.
3. Проверить `ConcurrentJUnitTestRunner` и показать замечания о параллельности и ресурсах.
4. Показать обработку неверного ключа и отмену запроса.
